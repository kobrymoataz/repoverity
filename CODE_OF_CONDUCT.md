# Community Code of Conduct

RepoVerity is an open-source project. Contributors are expected to communicate respectfully, discuss code and behavior rather than personal attributes, and welcome people with different experiences.

## Expected behavior
- Be constructive, patient and specific in technical reviews.
- Respect maintainers' time and community boundaries.
- Give credit for shared work and document sources when appropriate.
- Handle security concerns privately under [SECURITY.md](SECURITY.md).

## Unacceptable behavior
- Harassment, threats, discriminatory remarks or unwanted personal attention.
- Deliberately spamming Issues/PRs, impersonating contributors or fabricating engagement.
- Sharing another person's private tokens, secrets, or exported local backup files.

Maintainers may remove abusive comments, close inappropriate discussions or restrict contributions. Report concerns privately using [GitHub's reporting features](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam). For repository security reports, follow [SECURITY.md](SECURITY.md).
