# RepoVerity V0.2 release notes

## Included
- New responsive dashboard and repository explorer.
- Profile statistics loaded from the public GitHub REST API.
- Repository language overview and metadata coverage indicators.
- README, contribution and security policies.
- Automated quality checks and GitHub Pages deployment workflow.

## Accuracy
- Stars and forks cover only the sampled repositories (up to 100).
- Metadata indicators are not security ratings.
- No follower or star automation.

## Next
- Prospective follower and star history tracking.
- Community and achievements educational tools.
