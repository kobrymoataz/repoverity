# Changelog

## [1.6.0] - Prepared for release

- Added optional GitHub OAuth sign-in through a same-origin Cloudflare Worker.
- Added D1-backed workspaces, repository watchlists, display preferences and explicit account deletion.
- Added server-side hashed sessions, secure cookie settings, state validation, scoped data queries and strict mutation guards.
- Preserved public-only GitHub Pages and existing browser-local growth, achievement and Explorer records.
- Added Cloudflare and GitHub OAuth setup documentation, backend tests and staged installation scripts.


## [1.5.0] - Prepared for release

- Added a focused evidence audit workbench inside the Repository Audit view.
- Added README content inspection, public community profile checks and GitHub Actions workflow evidence.
- Added optional root dependency manifest review for recognized languages.
- Added observed, review, unknown and informational findings with direct source links.
- Added bounded on-demand API requests, caching and Markdown/JSON exports.
- Kept the prior metadata advisor and all V1.4 analytics and local storage unchanged.
- Expanded deterministic tests and documented limits without claiming vulnerability detection.

## [1.4.0] - Prepared for release

- Added Developer Analytics Pro with portfolio metrics and a transparent last-push distribution chart.
- Added on-demand second-profile comparisons and repository contributor, release, issue and PR activity sampling.
- Added explicit per-endpoint failures, bounded in-memory caching, safe CSV exports and mobile layouts.
- Preserved V1.3 Explorer, V1.2 motion, and existing browser-local data formats.
- Documented measurement scope and the difference between unavailable data and zero results.

## [1.3.0] - Prepared for release

- Added manual GitHub pagination beyond the initial 100-repository sample.
- Added language, topic, status and search filters with four sorting modes.
- Added table and card layouts, three-repository comparison and CSV export.
- Added locally saved filter views per account, validation and explicit data scope labels.
- Preserved the V1.2 motion system and existing storage/backup formats.
- Added extensive unit tests and explorer documentation.

## [1.2.0] - Planned release

- Added Motion for React transitions for the developer workspace and navigation.
- Introduced GSAP scoped Overview reveal for actual loaded data.
- Added searchable Quick switch with Command K and Control K shortcuts.
- Animated time-aware growth chart paths without changing recorded observations.
- Added a motion preference that respects the user's operating system settings.
- Added motion policy tests and release documentation.

## [1.1.0] - Planned release

- Rebuilt the main interface as a nine-view developer workspace.
- Introduced a restrained, responsive design system, a new visual identity and repository data tables.
- Added direct workspace hash links and keyboard search shortcut.
- Preserved the public GitHub API and existing local history formats.
- Updated accessibility, documentation and release text checks.

## [1.0.0] - Pending publication

### Added
- Local-only backup and restore of growth history, follower goals, and manual achievement checklists.
- Backup validation, size limits, review panel and confirmation before replacing saved data.
- Optional clearing of RepoVerity's local records, without touching unrelated storage.
- Reusable error fallback, keyboard skip link, accessible status feedback, and reduced-motion styling.
- Deferred loading for secondary workspaces.
- Production GitHub Pages asset/path verification in both CI and deployment workflows.
- Project contributor templates, privacy and architecture documentation, release checklist.

### Improved
- Bounded in-memory GitHub snapshot cache.
- Clear distinction between public metadata scores, security reviews, and GitHub-issued badges.
- Stable-release labeling and release documentation.
